# Projetos de Estudo em Programação  

Este repositório reúne diferentes materiais de estudo em **programação em geral**, incluindo scripts, notebooks e desafios práticos.  
O objetivo é consolidar conhecimentos adquiridos em cursos, plataformas de prática e projetos pessoais, servindo como **portfólio de aprendizado contínuo**.  

---

## Destaques do Repositório

- Conjunto de **scripts SQL** para consultas, criação e manipulação de dados.  
- Notebooks de **exercícios resolvidos em Python**, cobrindo fundamentos da linguagem.  
- Projetos aplicados em ambientes de **dados e nuvem** (exemplo: Databricks).  
- Estrutura organizada para facilitar a consulta e reutilização de códigos.  

---

## Estrutura dos Arquivos

### 1. `API_Google_translator_Coursera_Sub_Indo_Extension-master.zip`  
- Projeto para utilização da API do Google Translator integrado a materiais de estudo.  

### 2. `SQL challenge - sqlbolt-com.sql`  
- Resolução de desafios do site [SQLBolt](https://sqlbolt.com/).  
- Prática de queries SQL em diferentes cenários.  

### 3. `estudos_databricks.md`  
- Anotações e estudos realizados no **Databricks**, abordando conceitos de Big Data e Spark.  

### 4. `python gerar_agenda.py`  
- Script em Python para automação de geração de agendas.  

### 5. `resolucao_de_exercicios_e_codigos_basicos_python.ipynb`  
- Notebook com exercícios resolvidos e exemplos práticos de Python.  
- Foco em lógica de programação e fundamentos da linguagem.  

### 6. `script_completo_de_comandos_SQL_SERVER.sql`  
- Script consolidado com comandos de **SQL Server**.  
- Inclui criação de tabelas, consultas e manipulação de dados.
